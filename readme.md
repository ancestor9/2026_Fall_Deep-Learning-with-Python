# 2026 Fall Deep Learning with Python 🧠🤖

본 저장소는 **2026년 가을학기 파이썬 기반 딥러닝(Deep Learning with Python)** 강의 실습 및 프로젝트를 관리하는 레포지토리입니다. 
파이이토치(PyTorch) 및 케라스(Keras/TensorFlow) 프레임워크를 활용하여 딥러닝의 기초 이론부터 최신 모델 실습까지 다룹니다.

---

## 📌 주요 내용 (Contents)

- **딥러닝 기초 (Fundamentals of Deep Learning)**
  - 인공신경망(ANN), 퍼셉트론, 활성화 함수, 역전파 알고리즘
- **컴퓨터 비전 (Computer Vision)**
  - 합성곱 신경망(CNN), 이미지 분류, 객체 탐지(Object Detection)
- **자연어 처리 및 시계열 (NLP & Time Series)**
  - 순환 신경망(RNN, LSTM, GRU), 트랜스포머(Transformer) 구조 이해
- **생성형 AI & 최신 아키텍처 (Generative AI & Advanced Models)**
  - Autoencoder, GAN, Diffusion, LLM 파인튜닝 실습
- **팀/개인 프로젝트 (Projects)**
  - 실전 데이터셋 기반 모델 구현 및 성능 최적화
